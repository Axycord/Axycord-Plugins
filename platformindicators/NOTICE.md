# Source provenance

The plugin code and icons are adapted from the MIT-licensed
[APlatformIndicators Microcord port](https://github.com/mmaarij123/APlatformIndicators-Microcord).
The build and discovery configuration follows the
[Axycord Plugin Template](https://github.com/Axycord/Axycord-Plugin-Template/tree/2a36ff842ede7b4da312b41005782f3146588ca9).

The template's [provenance notice](https://github.com/Axycord/Axycord-Plugin-Template/blob/2a36ff842ede7b4da312b41005782f3146588ca9/NOTICE.md)
describes inherited files from the Microcord template that had no standalone license.
Gradle wrapper files retain their original Apache-2.0 terms. The separately distributed
[Axycord host and SDK](https://github.com/Axycord/Axycord) retain their AGPL-3.0-only terms.
